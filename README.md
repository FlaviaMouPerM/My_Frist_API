# My First API

## English

A project from **The Odin Project** focused on working with APIs.

Users can select an option from a form, and a corresponding GIF is fetched from an API and displayed on the page.

### What I learned

* How to work with APIs
* Fetching data with JavaScript
* Working with asynchronous functions
* Handling user input
* Updating the DOM dynamically

---

## Português

Um projeto do **The Odin Project** focado no uso de APIs.

O usuário pode escolher uma opção em um formulário, e um GIF correspondente é buscado através de uma API e exibido na página.

### O que aprendi

* Como trabalhar com APIs
* Como buscar dados com JavaScript
* Trabalhar com funções assíncronas
* Manipular entradas do usuário
* Atualizar o DOM dinamicamente
